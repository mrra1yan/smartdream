## Bug: PiP shows না যখন background-এ auto-like চলছে

### Root Cause
`useEffect([ads])`-এ যখন `ads.length === 0` (ad batch শেষ, নতুন batch আসেনি), তখন `PipModule.setPipReady(false, '[]')` call হয়। User যদি এই 1-3 সেকেন্ডের gap-এর মধ্যে Home press করে, তাহলে `onUserLeaveHint()` দেখে `pipReady = false` → PiP enter করে না।

### Fix (1 file, 3 lines)
`MobileApp/App.tsx` line 254-261 — `pipReady` set করার condition-এ `pipActiveRef.current` check যোগ করা:

```diff
- if (ads.length > 0 && autoLikeActiveRef.current) {
+ const shouldBePipReady = autoLikeActiveRef.current &&
+   (ads.length > 0 || pipActiveRef.current);
+ if (shouldBePipReady) {
    PipModule?.setPipReady(true, JSON.stringify(ads));
  } else {
    PipModule?.setPipReady(false, '[]');
  }
```

Same pattern already used for service stop prevention (line 271-272).
